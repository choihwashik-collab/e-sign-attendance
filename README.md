# 📱 연수 전자 서명 및 공식 출석부 생성 시스템 (E-Sign Attendance System)

연수 및 교육 진행 시 번거로운 종이 수기 서명과 미참석자 추적 문제를 해결하기 위한 **스마트폰 터치 전자 서명 및 실시간 출석 관리 웹 애플리케이션**입니다.

---

## 🌟 주요 기능

1. **사전 명단 지능형 입력 (부서별 PDF / Excel / Text)**:
   - 부서별로 정리된 **PDF 파일** 또는 **엑셀(.xlsx, .csv)**을 올리면 부서명과 성명, 직급을 자동 추출합니다.
   - 텍스트 복사-붙여넣기로도 간편하게 등록 가능합니다.

2. **프로젝터용 대형 QR코드 & 링크 배포**:
   - 연수 시작 시 화면에 빔프로젝터용 대형 QR코드를 띄워 참석자가 스마트폰 카메라로 스캔하여 1초 만에 입장할 수 있습니다.

3. **스마트폰 모바일 터치 전자 서명**:
   - `[부서 선택]` ➔ `[내 이름 선택]` ➔ `[서명 패드에 손가락/펜으로 서명]` ➔ 완료.
   - 부드러운 필압/베지어 곡선 알고리즘 적용 (되돌리기, 지우기 지원).

4. **미등록자 현장 직접 추가**:
   - 사전 명단에 이름이 없는 참석자도 `[+ 현장 직접 등록]` 버튼으로 본인 부서와 이름을 입력하고 즉시 서명 가능.

5. **실시간 서명 현황 대시보드 (진행자 모드)**:
   - 총 대상자, 서명 완료자, 미서명자 통계 및 실시간 서명률(%) 프로그레스 바.
   - **미서명자만 보기 필터**로 아직 서명하지 않은 사람을 즉시 확인 가능.

6. **공식 서명부 PDF 자동 생성 & 엑셀 내보내기**:
   - 실제 수기 서명 이미지가 삽입된 **A4 공문서 규격 서명부 PDF** 원클릭 다운로드 및 인쇄.
   - 엑셀(.xlsx) 출석 명단 다운로드 지원.

7. **100% 무료 배포 & 구글 스프레드시트 연동 (비용 0원)**:
   - **GitHub Pages**: 영구 무료 웹 호스팅 (어디서나 모바일 접속 가능).
   - **Google Apps Script**: 구글 스프레드시트에 실시간 출석/서명 내역 자동 기록.
   - 브라우저 자체 로컬 저장소(LocalStorage) 내장으로 인터넷 연결이 없어도 100% 독립 실행 가능.

## 🚀 사용 방법

### 1. 로컬에서 즉시 사용하기
- `index.html` 파일을 더블클릭하여 크롬, 엣지, 웨일, 사파리 등의 웹 브라우저에서 열면 즉시 작동합니다.

### 2. 깃허브(GitHub Pages)에 1분 만에 무료 배포하기
1. GitHub에 새 저장소(Repository)를 생성합니다 (예: `e-sign-attendance`).
2. 이 폴더의 모든 파일(`index.html`, `css/`, `js/`, `google-apps-script/` 등)을 저장소에 업로드(Push)합니다.
3. GitHub 저장소의 **[Settings]** ➔ **[Pages]** 메뉴로 이동합니다.
4. **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택하고 **[Save]**를 클릭합니다.
5. 1~2분 후 생성되는 `https://<아이디>.github.io/<저장소이름>/` 링크를 통해 스마트폰 및 PC에서 언제 어디서든 접속할 수 있습니다!

### 3. 구글 스프레드시트 실시간 연동하기
- 자세한 내용은 [google-apps-script/README_GAS.md](google-apps-script/README_GAS.md) 문서를 확인해 주세요.
- Apps Script의 웹 앱 URL을 관리자 설정창에 입력하기만 하면 실시간 동기화가 활성화됩니다.

```
│   ├── pdf-generator.js         # A4 공식 서명부 렌더링 및 PDF 생성기

└── README.md                    # 전체 프로젝트 설명서
```
