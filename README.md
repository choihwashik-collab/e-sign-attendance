# 연수 전자 서명·출석 관리 앱 (보안 v10)

진행자 명단 관리, 참석자 터치 서명, PDF/Excel 출력, Google Sheets 저장을 지원하는 정적 웹 앱입니다.

## 중요: 배포 전 필독

로컬 코드만 업데이트된 상태에서는 기존 운영 서버가 보호되지 않습니다.
**[보안 변경·재배포 안내](SECURITY_DEPLOYMENT.md)**에 따라 Google 서버와 웹 화면을 함께 업데이트하고 구버전 배포를 중지하세요.

## 사용 모드

- 서버 모드: Google Apps Script의 ADMIN_KEY로 진행자 로그인 → 연수 생성/선택 → 명단 입력 → 참석자 서명 → 서버 저장 확인.
- 단일 기기 모드: 같은 브라우저에만 명단과 서명을 보관합니다. 로그인 보호나 휴대폰 공유는 없으며 공용 기기에 적합하지 않습니다.
- 기본 비밀번호와 마스터 비밀번호는 폐지했습니다. 관리자 키는 소스나 QR에 넣지 않습니다.
- 일반 사용자는 키 없이 접수 중인 연수 목록과 이름·소속·처리 여부만 조회합니다. 명단 추가·삭제·서명 원본·상세 비고·기본명단은 진행자 전용입니다. 참석자는 같은 이름을 다시 선택하여 재서명하거나 조퇴·출장 등의 사유를 저장할 수 있습니다.
- 공개 목록과 공용 QR은 본인 인증 수단이 아닙니다. 앱 주소를 아는 사람은 접수 중인 연수의 이름을 선택할 수 있으므로 진행자의 현장 확인이 필요합니다.

## 추가 기능

- 관리자 기본명단 저장·수정·삭제(최대 30개). 연수에 복사한 명단은 기본명단과 독립적으로 편집합니다.
- 성명·소속 변경은 인원 교체로 처리하며 해당 인원의 이전 서명·사유를 지웁니다.
- Excel은 서명 PNG를 파일 내부 그림으로 포함합니다. 조퇴·출장 등은 비고에 사유, 서명은 공란입니다.
- 재서명은 최신 기록으로 교체합니다. 오래 열린 화면의 변경은 충돌 오류로 보호합니다.

## 운영 제약

- 원격 저장은 인터넷이 필요합니다. 실패하면 서명을 유지하고 오류를 표시합니다.
- 최신 브라우저를 사용하세요. 외부 라이브러리는 CDN에서 받으므로 완전 오프라인 실행을 보장하지 않습니다.
- 한 묶음은 최대 200명, 연수 30개입니다. 명단 파일은 5MB, PDF는 50페이지까지입니다.
- 원격 데이터는 페이지 메모리에만 보관합니다. 기존 로컬 데이터는 자동 업로드·삭제하지 않습니다.
- 30일 자동 삭제는 Apps Script의 선택적 트리거입니다. 기관의 보관 정책을 확인하고 직접 설정하세요.
- 통계에서 병가·출장 등은 서명 완료에 포함하지 않습니다.
- Google 시트 직접 수정은 앱의 충돌 감지 대상이 아니므로 운영 중에는 앱으로 수정하세요.

## 실행·배포

정적 호스팅에 index.html, js/, css/를 배포합니다. css/tailwind.css도 포함하세요.
서버 설정: [Google Apps Script 안내](google-apps-script/README_GAS.md).

기존 브라우저의 자료를 옮기려면 서버 로그인 후 '기존 로컬 자료 → 서버 복사'를 명시적으로 실행합니다. 원본은 유지하고 새 서버 묶음을 생성합니다.

## 검증

```
node --test tests/security.test.cjs
```

테스트는 모의 Google 서버와 DOM을 사용합니다. 실제 운영 배포와 휴대폰 왕복 검증을 대체하지 않습니다.

CSS 재생성:

```
npx --yes tailwindcss@3.4.17 -i ./css/tailwind-input.css -o ./css/tailwind.css --minify
```

## 주요 파일

- index.html / css/: 화면 및 정적 CSS
- js/app.js: 인증 흐름, 상태, 명단, 서명 및 UI
- js/gas-sync.js: 인증된 POST와 저장 확인 응답
- js/pdf-parser.js / js/pdf-generator.js: 명단 추출과 출력
- js/signature-pad.js: 서명 캔버스 및 이미지 용량 제한
- google-apps-script/Code.gs: 서버 권한 검사, 초대, 데이터 저장
- tests/security.test.cjs: 회귀 테스트
- SECURITY_DEPLOYMENT.md: 직접 할 일, 사용상 변화, 남는 위험
