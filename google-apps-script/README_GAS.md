# 📊 구글 스프레드시트 1분 연동 가이드

전자 서명 웹 앱과 구글 스프레드시트를 연동하면, 참석자가 폰으로 서명할 때마다 **구글 시트에 실시간으로 서명 일시와 출석 상태가 자동 기록**됩니다!

---

## 1. 구글 스프레드시트 생성 및 코드 붙여넣기
1. [Google 스프레드시트](https://sheets.new)를 새로 엽니다.
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
3. 편집창에 있는 기본 코드를 지우고, `Code.gs` 파일의 전체 내용을 복사하여 붙여넣습니다.
4. 상단의 **💾 저장 (디스크 아이콘)** 버튼을 누릅니다.

---

## 2. 웹 앱(API)으로 무료 배포
1. 우측 상단의 파란색 **[배포]** 버튼 ➔ **[새 배포]**를 클릭합니다.
2. 톱니바퀴 아이콘 ⚙️을 눌러 유형을 **[웹 앱]**으로 선택합니다.
3. 설정을 다음과 같이 지정합니다:
   - **설명**: `연수 서명 API`
   - **다음 사용자 권한으로 실행**: `나 (내 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자(Anyone)`** ⚠️ *반드시 모든 사용자로 선택해야 스마트폰에서 통신할 수 있습니다.*
4. **[배포]** 버튼을 누르고, 승인 요청 창이 뜨면 계정 권한을 승인합니다.
5. 배포 완료 화면에 나타나는 **웹 앱 URL** (예: `https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 기존 배포를 수정한 경우에는 **배포 관리 → 연필 아이콘 → 새 버전 → 배포**를 선택해야 새 코드가 적용됩니다.

---

## 3. 웹 앱 관리자 화면에 URL 등록
1. 본 전자 서명 웹 앱의 **[⚙️ 진행자 모드]** ➔ **[📊 구글 시트 연동]** 탭으로 이동합니다.
2. 복사한 웹 앱 URL을 붙여넣고 **[저장 및 연결 테스트]** 버튼을 클릭합니다.
3. 초록색 `연결 성공!` 메시지가 표시되면 연동이 완료됩니다!

연결 후 관리자 화면에서 명단을 동기화하거나 QR 화면을 열면 연수 묶음 전체가 시트에 저장됩니다. QR로 접속한 휴대폰은 별도의 브라우저 저장 데이터가 없어도 Google Sheets에서 명단을 불러옵니다.

---

## 4. 30일 자동 정리 사용하기

Apps Script 편집기에서 함수 목록의 `setupCleanupTrigger`를 한 번 실행하고 권한을 승인합니다. 이후 하루에 한 번 30일이 지난 연수 묶음과 해당 출석 시트가 자동 삭제됩니다.
